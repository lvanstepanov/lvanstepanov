# KASE Compass

Ориентир купона для нового выпуска облигаций на KASE: доходность ГЦБ того же срока плюс спред прошлых сделок, с учётом истории эмитента. Похожие сделки со ссылками на сообщения KASE, состав покупателей, цена 0,1 п. п. в тенге и честная проверка точности на истории.

Учебный концепт-прототип для кейс-чемпионата KASE. Это не официальный сервис KASE и не инвестиционная рекомендация.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # контрольные цифры SPEC.md, раздел 6
npm run build      # статическая папка dist/
npm run preview    # посмотреть сборку: http://localhost:4173
```

`dist/` работает без сервера данных: все данные (`compass-pack/data/compass_data.json`) вшиты в сборку, запросов к kase.kz нет.

## Как выложить бесплатно

**Netlify (без аккаунта CLI):**
1. `npm run build`.
2. Откройте https://app.netlify.com/drop и перетащите папку `dist/`. Ссылка готова сразу.

**Vercel:**
1. `npm run build`.
2. `npx vercel deploy dist --prod` и ответьте на вопросы (первый раз попросит войти).

Сборка использует относительные пути (`base: './'`), поэтому `dist/` работает и из подпапки, и с GitHub Pages.

## Устройство

| Путь | Что |
|---|---|
| `src/lib/compass.ts` | чистые функции: кривая ГЦБ, квантили, ориентир, сравнение, окно рынка, проверка на истории |
| `src/lib/compass.test.ts` | тесты на все контрольные цифры |
| `src/components/Instrument.tsx` | компас-прибор: шкала 12–26%, коридор, ГЦБ, стрелка |
| `src/screens/` | восемь экранов: `#guide`, `#map`, `#market`, `#spreads`, `#deals`, `#buyers`, `#check`, `#full` |
| `src/lib/map.ts`, `src/screens/Map.tsx` | «Карта рынка»: данные, корзины цвета, раскладка (`d3-hierarchy`), подписи, панель эмитента |
| `src/lib/map.test.ts` | пересчёт карты из `compass_data.json`, контрольные цифры, свойства раскладки |
| `compass-map-pack/` | бриф карты, эталон, скрипт сборки `map_data.json` |
| `src/styles.css` | токены палитры (светлая и тёмная тема), сетка, таблицы |
| `compass-pack/` | бриф, спецификация, данные, эталон и знак |
| `docs/screens/` | скриншоты: 1440 и 390 px, светлая и тёмная тема |

Стек: Vite, React, TypeScript; графики — SVG вручную, раскладка карты — `d3-hierarchy`; без UI-китов.

Карта открывается по ссылке с видом: `#map?size=n&color=price`. С панели эмитента кнопка «Рассчитать ориентир купона →» ведёт на `#guide` с этим эмитентом; на «Ориентире» под эмитентом ссылка «Этот эмитент на карте рынка →» открывает его панель на карте.
