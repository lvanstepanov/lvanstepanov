# compass-map-pack: экран «Карта рынка» для KASE Compass

## Как запустить

1. Положите папку `compass-map-pack` в корень проекта сайта, рядом с `compass-pack`.
2. Напишите Claude Code одной строкой:
   `Прочитай compass-map-pack/PROMPT_MAP.md и добавь экран «Карта рынка» строго по нему.`
3. Когда он закончит, сверьте на экране три вещи:
   - заголовок по умолчанию — «65% денег рынка привлекли квазигосударственные компании»;
   - в режиме «Размещения» плитка КФУ — «34 размещения»;
   - подсказка KMF Банк — «недобор в 4 из 9», «дороже типа на 1,82 п. п.».

## Что внутри

| Путь | Что это |
|---|---|
| `PROMPT_MAP.md` | Промпт: место на сайте, данные, раскладка, цвет, подписи, взаимодействие, тексты, контрольные цифры, проверка. |
| `data/map_data.json` | Данные карты: 41 эмитент, 6 типов, 187 сделок со ссылками KASE, корзины цвета, тексты, контрольные цифры. |
| `data/map_issuers.csv` | Те же эмитенты таблицей, со ссылками на все их сообщения KASE. |
| `tools/build_map_data.py` | Как посчитан `map_data.json`. Из `compass-pack/data/compass_data.json` воспроизводит его байт в байт. |
| `reference/map_reference.html` | Рабочий эталон карты в одном файле: логика, раскладка и поведение. Открывается в браузере. |
| `reference/screens/` | Скриншоты эталона: десктоп, телефон, тёмная тема, подсказка, панель эмитента, таблица. |

## Что важно не сломать

- **Числа на плитках не обрезаются.** Если строка не помещается, её нет.
- **Только данные из файла.** Каждая сделка открывается ссылкой на сообщение KASE.
- **Другие экраны не меняются.** Контрольные цифры «Ориентира» и «Проверки» те же.
