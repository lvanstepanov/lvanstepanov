# compass-pack: всё для сайта KASE Compass

## Какой промпт взять

| Задача | Файл |
|---|---|
| Новый сайт с сильным дизайном | `PROMPT_DESIGN.md` |
| Перенести Compass в существующий сайт с Capital Window | `PROMPT.md` |

## Как запустить

1. Распакуйте архив в папку, где открыт Claude Code. Рядом с вашими файлами должна лежать папка `compass-pack`.
2. Напишите Claude Code одной строкой:
   `Прочитай compass-pack/PROMPT_DESIGN.md и сделай сайт строго по нему.`
   Если плагин для сайтов запускается своей командой, вызовите её с этим же текстом.
3. Claude Code покажет план и начнёт работу. Стиль уже задан в промпте, на вопросы о нём отвечать не нужно.
4. Когда закончит, сверьте на экране три цифры:
   - BI Development, 2 года → **18,9–20,0%**;
   - новый эмитент МФО, 2 года → **20,7–22,0%**;
   - «Проверка на истории» → **64% против 45%**.

## Что внутри

| Путь | Что это |
|---|---|
| `PROMPT_DESIGN.md` | Промпт для нового сайта: продукт, арт-дирекшн, палитра, шрифты, компас-прибор, запреты, экраны, проверка. |
| `PROMPT.md` | Промпт для переноса в существующий сайт. |
| `SPEC.md` | Спецификация: данные, формулы, 7 экранов, тексты, контрольные цифры. |
| `data/compass_data.json` | Все данные одним файлом: его подключает сайт. |
| `data/deals.csv`, `data/gcb.csv`, `data/backtest.csv` | Те же данные в CSV, со ссылками на сообщения KASE. |
| `data/acceptance.json` | Контрольные цифры для тестов. |
| `reference/compass_reference.html` | Рабочая версия в одном файле: логика верная, дизайн черновой. |
| `reference/screens/` | Скриншоты текущей версии: десктоп, телефон и тёмная тема. |
| `brand/` | Знак компаса для шапки и большой компас-прибор в светлой и тёмной версии. |

## Что важно не сломать

- **Не чат-бот.** В продукте не должно быть чата или «ИИ-помощника»: это прямое ограничение кейса.
- **Только реальные цифры.** Каждая цифра считается из данных, у каждой сделки есть ссылка на сообщение KASE.
- **Дисклеймер в подвале.** Пометка, что это учебный концепт, а не официальный сервис KASE.
